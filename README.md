# Dev Meet:-
Dev Meet is a MERN stack–based web application designed to help developers connect, network, and engage with each other. The platform provides a space where developers can discover like-minded professionals, interact based on shared interests and skills, and build meaningful connections within the developer community.
##

# 🚀 Features:-
* Developer profile creation
* Discover and connect with other developers
* Engage with developers based on Interests and skills
* Secure authentication and authorization
* Responsive and user-friendly UI
* Feed Page
##


# 🛠️ Tech Stack:-
 Frontend:
* React.js
* HTML
* CSS Or Tailwind
* JavaScript

 Backend:
* Node.js
* Express.js

 Database:
* MongoDB

 Stack:
* MERN (MongoDB, Express, React, NodeJS)
